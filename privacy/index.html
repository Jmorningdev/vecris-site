ヴェクリス プライバシーポリシー

このページは、アプリ「ヴェクリス」が、あなたのどの情報を、どこに置き、どこへ送るかを書いたものです。バージョン 1.0 が対象です。最終更新 2026年9月5日。

短くいうと、3つです。

  • あなたの記録は、この iPhone の中に置いています。預かるサーバーはなく、アカウント登録もありません。
  • 外に出るのは2つだけです。あなたが設定で外部の AI をオンにしたときの送信と、あなたが自分で書いて送るメールです。
  • 広告、アクセス解析、行動の追跡は入れていません。

この iPhone の中に置いているもの

次のものを、iPhone の中の、このアプリだけが使える場所に保存しています。ほかのアプリからは読めません。iPhone のバックアップには含まれます。

何を中身
手で入れた記録 気分、眠れた気、体重、カフェイン、生まれ年と性別（自分で入れた場合）
食事の記録 料理の名前、分量、栄養素の値、記録した時刻
手で入れた運動 種目、時間、セット、回数、入力した文
あなたの状況 選んだ立場、気にしていること、服薬の有無、主治医の許可、選んだ目的、手で入れた家庭血圧
習慣 登録した習慣の名前と、実行した日
使った記録 いつ何をしたか、相談タブに書いた質問文、返ってきた答え、失敗の理由、開いた画面の回数。新しいものから 2,000 件まで
知らせる時刻 「決まった時間に知らせる」を使う場合のみ。時刻と、オンかオフか。初期状態はオフです
設定 AI の接続の設定、見た目、通信した回数、各画面の一言の下書き
外部 AI の API キー 自分で入れた場合のみ。iPhone のキーチェーンに入り、この端末の中だけに残ります（バックアップにも他の端末にも出ません）

「使った記録」は、設定 →「使った記録」で全文を読めますし、その画面から消せます。

ヘルスケアから読んだ値そのものを、コピーして保存することはしていません。読んだ値は計算のあいだだけ使い、残るのはその結果（ふだんの範囲、ずれ、点）です。

以前の版には、不具合を追うための控え（diagnostics.txt）を書きためるしくみが入っていました。公開する版には入っていません。開発用のビルドでしか作られず、公開する版は、もし古い控えが端末に残っていた場合、最初の起動で削除します。

ヘルスケア（HealthKit）のデータ

あなたが許可した項目だけを読みます。読むのは、睡眠、心拍数、安静時心拍、心拍変動、呼吸数、血中酸素、手首の皮膚温、睡眠中の呼吸の乱れ、心肺機能、歩数、消費エネルギー、運動時間、スタンド、身長、体重、ワークアウトです。栄養の目安を出すために、生年月日と性別も読みます（これは別に許可を聞きます）。

書き込みは体重だけです。これも初期状態ではオフで、設定でオンにしたときだけヘルスケアに書きます。ほかの項目を書き換えることはありません。

ヘルスケア由来のデータを、広告、宣伝、第三者への販売、他社のデータ収集に使うことは一切ありません。フィードバックのメールにも、ヘルスケア由来の値は入りません。

外部の AI（Google Gemini）

初期状態では、外部の AI に何も送りません。送るには、次の3つが揃う必要があります。1つでも欠けたら送りません。

  • AI プラン（App Store の定期購読）に登録する
  • 設定 →「AI の接続先」で「外部のモデルを使う」をオンにする
  • 行き先の説明を読んだうえで「送ってよい」をオンにする

送るもの

  • 指標の数値、ふだんの範囲、点などの集計した値
  • アプリが組み立てた要約の文
  • 食事の写真（送る前に、長い辺を 1024 ピクセルまで縮めます）
  • その写真に自分で添えたメモの文
  • 運動を文で記録したときの、その文（「腕立て伏せを30秒やって10秒休憩を4分間」など）
  • 設定で選んだ目的（「よく眠りたい」など。指示文の中に1〜2文の形で入ります）
  • 参照した研究論文の題、誌名、要旨（英語のまま。1本あたり最大 700 字）
  • 相談タブに書いた質問文（下の但し書きをお読みください）

相談タブの質問文だけは、送る前に、この iPhone の中で1回ふるいにかけます。病名・治療名・薬の名前は「（病気の名前）」のような言い方に置き換え、「◯◯さん」「◯◯先生」の名前の部分は落とします。置き換えた結果は、送る前にその場で画面に出します。ただし、このふるいは語の表と照らし合わせるもので、すべての病名・薬名を拾えるわけではありません。

送らないもの

  • あなたが選んだ状況（治療を受けている、治療を終えた、家族を支えている、など）
  • 気にしていること、服薬の有無、家庭血圧
  • 氏名、生年月日
  • カレンダーの予定（下の「カレンダー」をお読みください）

送り先と、その扱い

送り先は Google LLC（米国）の Gemini API です。Google はこのアプリの委託先として処理を行います。Google 側の条件は ai.google.dev/gemini-api/terms をご覧ください。

この通信は、開発者（運営）が Google と結んだ契約で行います。AI の鍵（API キー）は開発者が持っています。あなたが鍵を取得したり、入力したりすることはありません。あなたの Google アカウントとも結びつきません。

いまは Gemini API の無料の利用枠で動いています。Google は無料の枠について、送った内容と応答を自社製品の改善に使い、人間の担当者が読むことがあると明記しています。有料の枠に切り替えると使われなくなります（Google の規約が有料の場合について「プロンプトと応答を製品改善に使わない」と定めています）。切り替えたときは、この文もアプリの設定画面の説明も書き替えて、同意をもう一度おうかがいします。上の設定画面にも同じ説明を出しています。

AI プラン（定期購読）

外部の AI を使う機能は、AI プラン（App Store の定期購読）に登録した方だけがお使いになれます。記録・グラフ・この iPhone の中のモデルが書く短い文は、登録しなくてもいままでどおり使えます。

支払いは App Store が処理します。カード番号などの支払い情報が開発者に渡ることはありません。開発者の側で分かるのは、この iPhone で AI プランがいま有効かどうかだけで、それも iPhone の中で判定しているだけです（開発者のサーバには送りません）。

解約は、iPhone の「設定 → 自分の名前 → サブスクリプション」からいつでもできます。アプリの中からは解約できません（App Store の定期購読は Apple の画面で管理する決まりです）。

通信の量には、アプリ側で上限を置いています。1日 60 回・1分 6 回で止まります。今日いくつ使ったかは、設定 →「AI の接続先」→「通信の量」で見られます。

外部の AI をオフに戻せば、その時点から送信は起きません。すでに送ったものの扱いは、上の Google の条件に従います。

カレンダー

「集中」タブで、その日の空いている時間帯を出すために、カレンダーの予定を読みます。読むのは、あなたが許可したときだけです。見ているのは予定が入っている時間帯で、予定の内容（件名・場所・メモ・参加者）を保存することも、端末の外に送ることもありません。書き込みもしません。

許可を取り消すには、設定 → プライバシーとセキュリティ → カレンダー → ヴェクリスを開いてください。許可しない場合も、集中タブのほかの機能はそのまま使えます。

決まった時間に知らせる

設定 →「決まった時間に知らせる」をオンにすると、選んだ時刻に通知が届き、通知の上で気分と眠れた気を記録できます（アプリを開かなくても記録できます）。初期状態ではオフです。

この通知は、すべてこの iPhone の中で組み立てて、この iPhone が鳴らします。通知を出すためにサーバーへ通信することはありません。あなたが何を記録したか、通知を開いたかどうかを、外に送ることもありません。

止めるときは、同じ画面でオフにするか、設定 → 通知 → ヴェクリスから切ってください。

アプリが本物かどうかの確認

アプリになりすまして通信されることを防ぐため、Apple の App Attest と Google の Firebase App Check というしくみを使っています。ここで確かめているのは「このアプリが、改造されていない本物かどうか」だけです。

このとき Apple と Google に渡るのは、端末とアプリが本物であることの証明と、アプリを入れるたびに作られる識別子です。健康の値、写真、記録、氏名は含まれません。この識別子を広告に使うことも、他社のデータと結び付けることもありません。

フィードバックのメール

設定 →「不具合を知らせる」を開くと、メールの下書きができます。アプリがサーバーへ何かを送ることはなく、送信を押すのはあなたです。下書きの全文は、送る前に画面で読めます。

下書きに最初から入るのは、アプリの版・iOS の版・機種の型名の3行だけです。「詳しい記録も一緒に送る」にチェックを入れたときだけ、次の要約が付きます。

  • 入るもの — 種類ごとの件数、失敗した理由、かかった時間、応じたモデル名、開いた画面の回数
  • 入らないもの — あなたが書いた質問文と返ってきた答え、食事の内訳、体重、気分、睡眠、歩数、心拍などヘルスケアの値、「あなたの状況」、写真、画面の写し

広告・解析・追跡について

  • 広告は表示しません。広告の仕組み（SDK）は入れていません。
  • アクセス解析の仕組みは入れていません。Firebase Analytics も入れていません。
  • 広告識別子（IDFA）を読みません。トラッキングの許可も求めません。
  • あなたの情報を、他社に売ったり渡したりしません。

お子さまについて

ヴェクリスは、お子さま向けに作ったアプリではありません。13歳未満の方に向けて情報を集めることはしていません。

データの消し方

  • 使った記録だけ — 設定 →「使った記録」→「記録をすべて消す」。
  • 外部 AI の API キー — 設定 →「AI の接続先」→「キーを削除する」。
  • すべて — アプリを削除してください。アプリが保存していたものは、iOS がまとめて削除します。上に書いた「診断の控え」も、このときに消えます。

ヘルスケアに入っているデータは、アプリを削除しても残ります。読み取りの許可を取り消すには、設定 → プライバシーとセキュリティ → ヘルスケア → ヴェクリスを開いてください。設定でオンにして体重をヘルスケアに書いていた場合、その体重はヘルスケアアプリから削除できます。

アプリの中の記録について、内容の確認・訂正・削除のご希望があれば、上の連絡先までお知らせください。ただし、記録はあなたの iPhone の中にしかないため、こちらから中身を見ることも、消すこともできません。操作の方法をご案内する形になります。

医療についての位置づけ

ヴェクリスは医療機器ではありません。診断も治療もせず、病気の有無を判定しません。出しているのは「あなたのいつもと比べてどうか」だけです。治療中の方や、体調に不安のある方は、必ず主治医にご相談ください。

研究論文について

アプリには、PubMed / PMC で公開されている研究論文のうち、クリエイティブ・コモンズ表示（CC BY）または権利の放棄（CC0）のもの 1,080 本の要旨が入っています（内訳は CC BY が 1,076、CC0 が 4）。検索はアプリの中で行い、通信はしません。取得日は 2026年8月23日です。
